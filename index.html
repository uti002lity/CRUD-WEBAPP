Cara Menghubungkan ke Google Sheets API

1

Buat Google Apps Script

Buka Google Sheet kamu, klik Extensions > Apps Script. Tuliskan kode fungsi `doGet()` dan `doPost()` untuk mengolah data JSON.

2

Deploy sebagai Web App

Di Apps Script, klik Deploy > New Deployment. Pilih jenis Web app dan atur akses "Who has access" menjadi Anyone.

3

Panggil Endpoint URL via `fetch()`

Gunakan Web App URL yang diberikan Google untuk dipanggil melalui JavaScript di file HTML ini.
